# 設計

> 「You were state of the art, now you're just a baseline.」
> 每一個 state of the art，最後都會變成下一個的 baseline。

〈Baseline〉是一首 AI 架構的分手歌：從 1958 年的感知器一路唱到注意力機制和它的繼任者，每一段歌詞點名一個技術，再讓它被下一個取代。影片把每一句歌詞裡的技術，用它最直接、看得懂的畫面演出來，而且畫面上的每個數字都是真的算出來的。

這份文件寫的是「長什麼樣子、為什麼」。每個鏡頭的時間與內容在 [SHOTLIST.md](SHOTLIST.md)，怎麼做出來的在 [MAKING.md](MAKING.md)。

---

## 1. 原則

1. **歌詞是場景裡的物件，不是字幕。** 字刻在石碑上、寫在車廂側面、掛在隧道裡、鋪在地板上，跟著空間一起透視。全片沒有任何字幕條。
2. **唱到哪個字，畫面就演哪個字。** 一句歌詞拆成 2–4 個字的片語，每個片語在它被唱到的那一刻出現；正在唱的字是洋紅，唱完變骨白。
3. **一格一個主角，字要讀得到。** 正在唱的字必須整個在畫面裡、夠大、不跟別的字疊在一起。這三件事都用程式逐格檢查（見 MAKING.md 的品質檢查）。
4. **數字都是真的。** 濾波器是真的在 CIFAR-10 上訓練出來的，SVM 的邊界是真的擬合，梯度範數、LSTM 閘門、注意力權重、MoE 路由、INT4 量化、Bradley–Terry 分數、FlashAttention 的存取次數……全部來自 `tools/data/` 的腳本。
5. **公式用排版，不用截圖。** 71 條取自原始論文的公式用 MathJax 排版，出現在場景裡（注意力層、LSTM 招牌、SVM 圍籬）和背景城市的牆上。畫面上不出現論文頁面。
6. **一套顏色。** 墨黑、骨白、一階灰；洋紅只留給「現在的 state of the art」和「正在唱的字」。
7. **每一格都是時間的純函數。** 沒有亂數、沒有時鐘、沒有前一格的狀態；任何一格都能單獨重算，算出來一模一樣。

## 2. 色彩

| 名稱 | 色碼 | 用途 |
| --- | --- | --- |
| ink | `#0B0A0D` | 底色、字的暗色光暈（讓字在雜亂背景上浮出來） |
| ink2 | `#121016` | 城市牆面、面板 |
| panel | `#17151C` | 方塊、細胞、車廂的填色 |
| line | `#2A2731` | 細框線 |
| graphite | `#5C5966` | 次要線條、層板塔 |
| ash | `#9A96A3` | 標籤、被超越的東西（變成 baseline 的都轉成這個灰） |
| bone | `#EDEAF2` | 主要的字與線 |
| **mag** | `#FF2E7E` | **state of the art、正在唱的字、撞擊** |
| magHot | `#FF9CC4` | 雷射刻字的高溫色 |
| magDeep | `#A3104A` | 洋紅的暗部（濾波器雙色調、LED 暗點） |
| magDark | `#3A0A1E` | 地平線背光、洋紅的陰影 |

後製最後有一道 `unify`：洋紅以外的色相全部壓回 ink → bone 的亮度階，所以各場景原本設定的藍圖藍、示波器綠、冰藍都只剩明暗，全片看起來是同一部片。

## 3. 字

| 字型 | 用在 |
| --- | --- |
| Archivo 寬 125 / 900（`UF.wide`） | 砸下來的巨字：SIGMOID、ZERO、GONE、BASELINE、DEADLINE |
| Archivo 112 / 900（`UF.heavy`） | 一般歌詞行 |
| Archivo 75 / 900（`UF.cond`） | 車廂、窄的標籤 |
| IBM Plex Mono 500 / 700 | 數字、讀數、標籤、時間碼 |
| Cormorant Garamond | 停頓段（stop）的襯線字 |
| MathJax TeX 字型 | 所有公式 |

**字怎麼動**

- **卡拉 OK（`say3`）**：一個字的字母隨著發音逐一點亮，唱的當下是洋紅、唱完是骨白。
- **砸（slam）**：字出現時從 1 + slam 倍（通常 0.35–0.55）在 0.13 秒內以三次方縮回 1 倍。
- **片語（`chunk3`）**：一句切成 2–4 字的片語，每個片語在第一個字唱到時切換，前一個同時消失，不交疊。
- **巨字（`hero3`）**：單一個字佔滿畫面。
- **逐字透視排版（`text3`）**：每個字母各自投影到 3D 平面上，所以字能貼在任何斜面、地板、牆上。

## 4. 鏡頭

- **針孔相機**：所有 3D 都是在 Canvas2D 上用針孔投影畫出來的線、面、字（「2D 模擬 3D」），再交給 WebGL 做後製。
- **鏡頭（shot）**：每個場景有一組鏡頭，每個鏡頭是「時間 → 相機位置、目標、視角、滾轉」的函數。換鏡頭可以硬切，或在 `snap` 秒內用 outExpo 平滑接過去。
- **撞擊（hits）**：重拍上的震動與推鏡（pitch / yaw / roll 的衰減振盪加上視角縮放）。
- **全片相機**：場景之上還有一層，在 BASELINE、HERO、GONE、COLLAPSED、FALL 等字上做縮放撞擊與一圈震波折射，副歌與 drop 每個大鼓上 0.7% 的縮放脈衝。
- **轉場（seams）**：14 個場景之間用 `zoom`、`whip`、`slice`、`push`、`luma` 混接，混接本身也有動態模糊。其餘是設計好的「物件接力」硬切：SVM 院子裂成 DEPTH 的井、預副歌推進洋紅的 ∎ 接副歌、∇θ L 掉進地板接注意力磚……
- **讀得到優先**：鏡頭不跟著寫字頭或光點貼太近；整個字要在畫面裡；片語放在「唱到它時鏡頭正在看的地方」。

## 5. 空間：公式城市

每個場景都站在一座城市裡（`EnvCfg`，`app/src/scenes/_v.ts`）：

- **公式牆**：遠方的黑色牆面，上面是這個場景技術的公式（例如 GAN 段是 minimax 目標、DDPM 的前向過程與 loss、RoPE、RMSNorm、SwiGLU）。
- **層板塔**：一疊疊的方框，每拍有一道洋紅脈衝從底爬到頂。
- **注意力弧**：塔頂之間連著弧線（注意力相關的場景）。
- **重拍波**：在副歌的 NOW / BASELINE / DEADLINE、GONE、預副歌的 NEED 與封印上，一道洋紅波同時爬上全城的塔、點亮牆頂。
- **地面刻字**：鏡頭往下看時，地板上刻著同一組公式。
- **地平線背光**：一道很淡的洋紅暗光，讓城市有剪影。

城市是世界座標上的格點，鏡頭移動時它留在原地；只在離鏡頭夠遠的地方生成，永遠不擋到主角。地板是一面會反射的鏡面（模糊、往下漸淡，鏡頭往下看時依 Fresnel 減弱），空中有 1400 顆塵埃做視差。

## 6. 光與後製

bloom（全片統一減半）、halation、色差、顆粒、暗角、`unify` 色彩統一、sRGB 色調；彩色字的光暈收成一半的緊光暈，深色光暈保留（它是讓字在雜亂背景上讀得到的關鍵）。動態模糊是真的：每格依畫面動得多快，取 12、36 或 108 個子畫格平均（快速甩鏡會一直加到拖影連續為止）。

## 7. 四種重複的結構

歌有四次預副歌、四次副歌，影片讓同一個結構每次換一個主角，越來越重：

1. **預副歌：宣言（THE CLAIM）**——「X is all you need, the abstract guaranteed」。每次用該成分自己的結構把宣言蓋出來：DEPTH 是 152 層的井、MEMORY 是一排 LSTM 細胞的點陣、ATTENTION 是四塊磚之間的注意力、SCALE 是對數座標上一次放大十倍的字。結尾一塊黑玻璃石碑砸下，雷射刻出 GUARANTEED，洋紅的 ∎（證畢）砸上，鏡頭推進 ∎ 直到整個畫面是洋紅，副歌就從這片洋紅裡拉開。
2. **副歌：排行榜（THE BOARD）**——冠軍板上巨字 STATE OF THE ART → 挑戰者砸上塔頂、舊冠軍名牌一路摔到底（每個字頓一下）→ 落地的瞬間洋紅淹過地板寫著 BASELINE → 火箭升回榜首 → 倒數在 DEADLINE 上歸零。四次分別是 ILSVRC、WMT14、LAMBADA（冷的一輪，名牌被輕輕放下）、參數量（過載）。
3. **主歌：實驗室**——每句一個技術、一個結構、一組真實資料。
4. **結尾的迴圈**——FOOTNOTE（所有名字刻上紀念牆）→ THE FALL（整部片的冠軍疊成塔，歌者從塔頂掉回 BASELINE）→ ONE MORE TIME（繪圖機回來畫下一條新的線；最後一格就是第一格）。

## 8. 幾個關鍵畫面的設計理由

- **第一條線就是 baseline**：片頭繪圖機畫的 y = 0，就是之後每個冠軍摔下來落地的那條線，也是片尾畫新線的地方。
- **夜車是這首歌自己**：主歌二的每節車廂是一個唱到的字，n-gram、RNN、LSTM、seq2seq、注意力都在處理「這首歌」本身。
- **針是第一個字**：上下文視窗段落裡，乾草堆中的針是 token 0，也就是這部片唱的第一個字 Perceptron 的 P。
- **紀錄的樓梯**：「every breakthrough's just a baseline running late」——每個宣言在它的字上升起，一階比一階高；被超越的變灰，它的高度延伸成一條虛線，就是下一個要打敗的 baseline；最後一個未命名的 ? ? ? 升得比 SCALE 還高。紀錄不會掉下來，只會被超越。
- **長條被壓下去**：ImageNet 的錯誤率在 ATE、THE、BENCH-、-MARKS 四個拍點上一根根被壓到該年的數值，底下標出是哪個網路做到的。
